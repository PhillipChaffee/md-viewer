# Keyboard Shortcuts

## Tab Management

| Shortcut | Action |
| ---------- | -------- |
| Ctrl+T | Open file in new tab |
| Ctrl+W | Close current tab |
| Ctrl+Tab | Next tab |
| Ctrl+Shift+Tab | Previous tab |
| Ctrl+1-9 | Switch to tab 1-9 |

## File Operations

| Shortcut | Action |
| ---------- | -------- |
| Ctrl+O | Open file in new tab |
| Ctrl+E | Switch between the rendered document and its source (edit mode) |
| Ctrl+S | Save the edits made in edit mode |
| F5 | Toggle file watching |
| Ctrl+Q | Quit application |

## Navigation

| Shortcut | Action |
| ---------- | -------- |
| Alt+Left | Navigate back in history |
| Alt+Right | Navigate forward in history |
| Click link | Navigate in current tab |
| Ctrl+Click link | Open link in new tab |

## Search

| Shortcut | Action |
| ---------- | -------- |
| Ctrl+F | Open find bar (or refocus the input if already open) |
| Enter or ↓ | Jump to the next match in the current document |
| Shift+Enter or ↑ | Jump to the previous match in the current document |
| Esc | Close the find bar and clear highlights |

The find bar also has on-screen `↑` and `↓` buttons next to the match count for mouse navigation.

## View

| Shortcut | Action |
| ---------- | -------- |
| Ctrl+D | Next theme (Paper → Sepia → Dusk → Night) |
| Ctrl+Alt+→ | Widen the text column by 40 px |
| Ctrl+Alt+← | Narrow the text column by 40 px |
| Ctrl+Shift+E | Toggle file explorer |
| Ctrl+Shift+O | Toggle outline sidebar |
| Ctrl++ / Ctrl+= | Zoom in |
| Ctrl+- | Zoom out |
| Ctrl+0 | Reset zoom to 100% |
| ↑ / ↓ (when find bar is closed) | Scroll document up/down by line |
| Page Up / Page Down | Scroll document up/down by page |
| Ctrl+Scroll | Zoom in/out with mouse wheel |
| Shift+Scroll over a wide table | Scroll the table horizontally |

The **Aa** button in the top bar opens the appearance popover: theme
swatches, text size, a width slider with Fit window and Reset, and line
spacing. It is reachable from the keyboard: Tab to the button, Enter to
open it, Tab through its controls, Esc to close it.

The text column can also be resized with the mouse: drag either edge of the
column (a hairline and a resize cursor show where), and double-click an edge
to go back to the default width. The column stays centered, so both edges
move together.
